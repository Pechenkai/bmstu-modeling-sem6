# Лабораторные работу по математическому моделированию (3 курс)

Репозиторий с лабораторными работами по численному моделированию. Решения оформлены в Jupyter Notebook и содержат реализацию численных методов, расчёты и построение графиков.

## Состав репозитория

| Работа | Материалы | Содержание |
| --- | --- | --- |
| ЛР №1 | `lab_01/part_01`, `part_02`, `part_03` | Решение обыкновенных дифференциальных уравнений и сравнение численных приближений. |
| ЛР №2 | `lab_02/` | Модель радиационного переноса в цилиндре: интерполяция коэффициента поглощения, метод стрельбы, методы Рунге—Кутты второго и четвёртого порядков. |
| ЛР №3 | `lab_03/` | Решение краевых задач методом Галёркина и конечно-разностным методом с прогонкой. |
| ЛР №4 | `lab_04/main3.ipynb` | Нестационарная модель с температурным полем, источником излучения и итерационным расчётом. |

### ЛР №2 — радиационный перенос

В [задании](lab_02/10-03-2025-Задание_на_лаб_раб__2.pdf) рассматривается краевая задача для цилиндра, заполненного излучающим высокотемпературным газом. В ноутбуках выполнены:

- переход от уравнения второго порядка к системе первого порядка с потоком излучения `F`;
- линейная интерполяция в логарифмических координатах `ln(T)`—`ln(k)`;
- интегрирование методами Рунге—Кутты 2-го и 4-го порядков;
- поиск начального значения методом стрельбы и бисекцией;
- сравнение вариантов коэффициента поглощения и построение графиков.

Основной вариант находится в `lab_02/main.ipynb`. `main_tol.ipynb` использует `Decimal` для расчётов с повышенной точностью, а `test.ipynb` — альтернативная реализация.

### ЛР №3

- `main.ipynb` содержит постановку и реализацию метода Галёркина для краевой задачи, включая символьные вычисления с SymPy и визуализацию результата.
- `main2.ipynb` реализует конечно-разностную модель радиационного переноса: метод прогонки, последовательное сгущение сетки и вычисление потока.
- `task2_data_with_diff.txt` — данные расчёта для второго задания.

### ЛР №4

`lab_04/main3.ipynb` реализует расчёт нестационарного процесса. Используются табличные теплофизические свойства, интерполяция, решение трёхдиагональной системы и итерации по температуре и плотности энергии излучения.
